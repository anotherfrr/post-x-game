STAR CATCHER — a tiny neon arcade game built by an AI agent from one prompt: fly a ship, catch falling stars, dodge asteroids. One HTML file, no build step. Made for make.fun's "The agent builds a game from one prompt" bounty ($20 in USDC).

The one prompt: "Build me a tiny browser game: a neon star-catcher. Fly a ship, catch falling stars, dodge asteroids. One HTML file. Make it juicy."

## Run it

```sh
# Play it: open game.html in any browser — no build step, no network.
# Or run the entry program the way the grader does:
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the X post's address) to the output directory — the entry itself is the X post with the video of the agent building this game from one prompt.
